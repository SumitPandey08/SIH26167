# SatQuery AI — VLM Adaptation & 6-Stage Curriculum Pipeline

## 1. Adaptation Philosophy

General-purpose Vision-Language Models (VLMs) like LLaVA, Qwen2-VL, and InternVL are trained primarily on standard web photographs (horizontal perspective, single capture, RGB only). They struggle on Earth Observation imagery due to:
- **Nadir / Off-nadir geometry** (top-down views with arbitrary rotational orientation)
- **Multi-sensor modalities** (Synthetic Aperture Radar backscatter, 12-band multispectral)
- **Temporal dimensions** ($T_1$ and $T_2$ bi-temporal comparisons for change detection)
- **Spatial Grounding scale** (objects occupying 0.1% of multi-kilometer scenes)

To bridge this gap without the multi-million-dollar compute cost of training from scratch, SatQuery implements **Parameter-Efficient Fine-Tuning (PEFT / LoRA / QLoRA)** across a structured **6-Stage Remote Sensing Curriculum**.

---

## 2. The 6-Stage Curriculum

```
Stage 1: Alignment         ──► Contrastive remote sensing vision-language alignment
Stage 2: Captioning         ──► Detailed scene description & land-cover characteristics
Stage 3: Spatial VQA        ──► Spatial reasoning, object presence, counting, comparison
Stage 4: Visual Grounding   ──► Referring expressions with <box>[ymin, xmin, ymax, xmax]</box>
Stage 5: Change Reasoning   ──► Bi-temporal sequence modeling, building growth tracking
Stage 6: Optical-SAR Fusion ──► All-weather radar penetration & cross-modal reasoning
```

### Stage 1: Remote Sensing Vision-Language Alignment
- **Config**: `training/configs/stage1_alignment.yaml`
- **Target Datasets**: `BigEarthNet-v2`, `SEN12MS`
- **Goal**: Align the visual representations of top-down satellite imagery with geospatial concept vocabularies. Vision backbone features are projected into language space with frozen base weights.

### Stage 2: Remote Sensing Scene Captioning
- **Config**: `training/configs/stage2_captioning.yaml`
- **Target Datasets**: `VRSBench`, `LEVIR-CC`
- **Goal**: Train dense scene description capability, distinguishing agricultural parcels, forest types, urban density fabrics, and hydrological features.

### Stage 3: Remote Sensing Visual Question Answering (VQA)
- **Config**: `training/configs/stage3_vqa.yaml`
- **Target Datasets**: `RSVQA` (RSVQA-LR and RSVQA-HR), `FloodNet`
- **Goal**: Instill spatial reasoning, presence identification ("Is there a reservoir visible?"), counting ("Are there more than 10 buildings?"), and area comparison.

### Stage 4: Referring Expression Visual Grounding
- **Config**: `training/configs/stage4_grounding.yaml`
- **Target Datasets**: `VRSBench`, `DIOR-RSVG`
- **Goal**: Train the model to output precise normalized bounding boxes formatted as `<box>[ymin, xmin, ymax, xmax]</box>` in response to natural language queries.

### Stage 5: Bi-Temporal Change Detection & Change VQA
- **Config**: `training/configs/stage5_change_reasoning.yaml`
- **Target Datasets**: `LEVIR-CD`, `CDVQA`, `BRIGHT`
- **Goal**: Dual-image conditioning. Feed $T_1$ and $T_2$ observations into the vision projector to analyze building additions, urbanization, flood recessions, and structural disaster damage.

### Stage 6: Optical-SAR Multimodal Fusion
- **Config**: `training/configs/stage6_optical_sar.yaml`
- **Target Datasets**: `BigEarthNet-v2`, `SEN12MS`, `UrbanSARFloods`
- **Goal**: Cross-modal reasoning. Combine Sentinel-2 optical multispectral with Sentinel-1 dual-pol SAR (VV/VH) to delineate surface water and flood extents beneath thick cloud cover.

## 3. LoRA / QLoRA Architecture

Configured in `training/configs/lora_qlora_config.yaml`:
- **Adapter Type**: Low-Rank Adaptation (LoRA)
- **Rank ($r$)**: 16
- **Alpha ($\alpha$)**: 32
- **Dropout**: 0.05
- **Target Modules**: Attention projections (`q_proj`, `k_proj`, `v_proj`, `o_proj`) + MLP gates (`gate_proj`, `up_proj`, `down_proj`)
- **Quantization**: 4-bit NormalFloat (NF4) with double quantization for low-VRAM deployment
- **Compute Precision**: `bfloat16`


### Dry-Run Verification (CPU / Local Dev)
```bash

```

### Scientific Benchmark Evaluation
```bash
./scripts/satquery eval VRSBench --split test --max-samples 20
./scripts/satquery eval LEVIR-CD --split test --max-samples 20
```

## 5. Zero-Hallucination Discrepancy ($\Delta A$)

SatQuery enforces zero-hallucination verification by computing:
$$\Delta A = \frac{|A_{\text{text}} - A_{\text{grounded}}|}{A_{\text{grounded}}} \times 100\%$$

Any text claim generated by the VLM must match the deterministic segmentation mask generated by the specialist vision engines (TinyCD, SAR thresholding, building contours) with $\Delta A = 0.00\%$.
